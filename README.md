# Mochi Reader

Offline-first ebook, PDF, comic, and Markdown reader for Android in Kotlin and Jetpack Compose.

## Architecture & Highlights
- **100% Offline & Private (Milestone A)**: Zero `INTERNET` permission, zero accounts, zero analytics. Uses Android Storage Access Framework (`ACTION_OPEN_DOCUMENT_TREE` & `ACTION_OPEN_DOCUMENT`) and Photo Picker (`PickVisualMedia`).
- **Theme Engine & Theme Studio (Milestone A)**: 38+ bundled themes (Cute & Cozy, Catppuccin, Nord, Dracula, Rosé Pine, Gruvbox, Tokyo Night, Solarized, Everforest, Kanagawa, One Dark, Reading Classics, Cool/Hacker) with WCAG AA contrast checking, adaptive glass scrims, `.mochitheme` zip import/export, and live preview editor.
- **Liquid Glass & Expressive Design System (Milestone A)**: Thin design-system layer (`MochiMotionTokens`, `LiquidGlassSurface`, `MochiConnectedSegments`, `MochiWavyProgressBar`, `MochiBlobMascot`) with API 31+ `RenderEffect` blur, API 33+ AGSL top-edge refraction highlight, `Solid Chrome` mode, and `Reduce Motion` degradation.
- **Library & Bookshelf (Milestone A)**: Sample starter books (EPUB, PDF, CBZ, MD, TXT), WorkManager + SAF recursive scanner, SHA-256 duplicate detection, off-main-thread cover extraction/caching, Reading Now / Continue / Want to Read shelves, `LiquidGlassViewSwitcher` (Flat Grid / List / Glass Bookshelf, plus opt-in Skeuomorphic Wood Plank Bookshelf in Settings), long-press drag reorder & drop-to-stack, hierarchical Folders view with breadcrumbs, and Collections/Tags/Auto-Series.
- **Core Reader & Adaptive Tablet UI (Milestone B)**:
  - **Reflowable EPUB 2/3, GFM Markdown, TXT & CBZ Reader**: Pure-Kotlin parsers supporting XHTML/OPF/NCX/HTML5 Nav, YAML frontmatter cards, GFM tables, task checklists, fenced code blocks with syntax spans, footnotes, `[[wikilinks]]`, and Markdown vault backlinks.
  - **Compose Pagination & Locator Sync**: `TextMeasurer`-backed pagination with Knuth-Liang soft-hyphenation, per-book theme overrides, locator-based position save/restore across font/layout changes, undo-jump history, and `SharedTransitionLayout` cover-to-reader morph (honoring Reduce Motion).
  - **3-Tab `"Aa"` Liquid Glass Sheet & Controls**: Theme/Brightness, Text (`Literata`, `Inter`, `Lexend`, `JetBrains Mono`, `Caveat`, `Patrick Hand`, plus SAF `.ttf`/`.otf` font import), and Page/Layout controls with `LiquidGlassSlider`; interactive GPU Page Curl (`CURL`), Slide, Cover-Flip, Stack, Fade, Scroll, and None page turns; TOC + Backlinks sheet, bottom `LiquidGlassSlider` scrubber with chapter ticks & floating preview bubble, in-book search with context snippets, footnote popovers, pinch-zoom full-screen image viewer, tap-zone presets + gesture map, 5 auto-scroll modes, command palette (`go to <page>`, `theme <name>`, `studio`), reading ruler focus band, left-edge brightness swipe, and volume-key turns.
  - **Adaptive Tablet & Foldable UI**: `MochiAdaptiveContainer` (`COMPACT` / `MEDIUM` / `EXPANDED`), floating `LiquidGlassNavigationRail`, canonical supporting-pane Library inspector (`BookInspectorPane`), 2-column Settings, Theme Gallery & Global Notes, automatic Dual-Page Spread with spine shadow in Reader, and persistent side TOC / Book Annotations pane on `EXPANDED` displays.
- **Standard Annotations, Markdown Notes & Exports (Milestone C)**:
  - **Non-Destructive Room Annotations**: Highlights (8 theme-harmonized roles + Okabe-Ito Color-Blind-Safe palette option; 5 styles: `Highlight`, `Underline`, `Squiggly`, `Strikethrough`, `Washi Tape`), Markdown notes with formatting toolbar + live preview + `#tags` + `[[wikilinks]]` + Cozy stickers, and named bookmarks stored purely in Room—original EPUB/MD/TXT/CBZ files stay byte-for-byte untouched.
  - **In-Reader Selection & Inspection**: Long-press passage selection with Liquid Glass floating toolbar & word-range trimmers, Quick-Highlight mode, inline highlight tap popover, bookmark dialog, and filterable per-book Annotations panel with Undo Jump.
  - **Global Notes, Templates, Vault Sync & Quote Cards**: Cross-library searchable/filterable `"Notes"` tab with rendered Markdown notes and direct locator jump; customizable Room `ExportTemplateEntity` presets (`{{quote}}`, `{{note}}`, `{{page}}`, `{{chapter}}`, `{{color}}`, `{{tags}}`, `{{date}}`, `{{title}}`, `{{author}}`); SAF export to `.md`, `.json`, `.csv`, and Obsidian/Logseq Vault folder sync; off-main-thread `1080×1350` PNG Quote Card generator with SAF save and `FileProvider` share.
- **Offline Dictionary, Smart Lookup & Vocabulary Builder (Milestone D)**:
  - **Bundled SQLite FTS Dictionary & SAF Importers**: Bundled compact WordNet-style English lexicon indexed in SQLite FTS4 (`DictionarySqlStore`), plus offline SAF folder/file importers for StarDict (`.ifo`/`.idx`/`.dict`/`.dict.dz`), dictd (`.index`/`.dict`/`.dict.dz`), and Wiktionary/Kaikki (`.jsonl`/`.tsv`/`.csv`/`.gz`/`.zip`), with priority ordering, enable/disable toggles, and per-book-language defaults.
  - **Smart Lookup, Glass Popup & System Translate**: Long-press passage/word toolbar with instant 1–3 word definition preview, `Define` and `Translate` actions, optional `Tap Word to Define` reader mode, Liquid Glass `DictionaryGlassPopup` with system `TextToSpeech` pronunciation, English lemmatization/inflection & irregulars (`EnglishLemmatizer`), 2/3-word phrase/idiom context matching, Damerau-Levenshtein `"Did you mean"` suggestions, and opt-in external system translation (`ACTION_TRANSLATE` / `ACTION_SEND`) with zero network permissions.
  - **Vocabulary Builder, SM-2 & Anki Export**: `"Vocabulary"` sub-tab inside the `"Notes"` hub with SuperMemo SM-2 spaced repetition flashcard sessions (`Again`/`Hard`/`Good`/`Easy`), context sentences linked back to source books, Anki-compatible `.tsv` / `.csv` + Markdown export via SAF, and `"Highlight Unknown Words"` underlining mode inside the reader.
- **Fixed-Layout PDF Reader & CAD Annotation Studio (Milestone E)**:
  - **Thread-Safe PDF Rasterizer (`PdfPageEngine`)**: Android `PdfRenderer` wrapped with coroutine `Mutex` and LRU bitmap cache, Fit-Page / Fit-Width modes, non-destructive Auto Margin Crop detection, hue-preserving Smart Dark Invert, pinch-zoom (up to 10x), smart double-tap zoom, and `PdfThumbnailsSheet`.
  - **Vector CAD Studio (`AnnotationStudioOverlay`, `StudioGeometry`, `StudioCanvasRenderer`)**: Select, pressure-sensitive Pen, Highlighter, Line, Arrow, Rectangle, Ellipse, Polygon, Revision Cloud, Leader Callout, Distance/Area Measurement tools, Pinned Note, Stamps, Spotlight cutout, and Scale Calibration (`mm`/`cm`/`m`/`in`/`ft`). Precision snapping (Endpoint, Midpoint, Center, Intersection, Page Edge, Grid), 45° Ortho constraint, stylus hover reticle, 2.5x precision loupe HUD, layer manager (visibility, lock, opacity), properties inspector, multi-select copy/paste/align, unlimited Undo/Redo command stack, and SAF non-destructive Annotated PDF Copy / Layered SVG / JSON exports (`StudioExporter`).
- **Interactive Finger-Following Page Curl & Motion Polish (Milestone F)**:
  - **GPU / Canvas Page Curl (`PageCurlEngine`)**: Works identically across both reflowable EPUB/MD/TXT spreads and fixed-layout PDF pages with velocity-driven flicks, mirrored page backs, AGSL `RuntimeShader` cylindrical specular shading on API 33+ (Canvas gradient fallback on API 24–32), soft shadow casting, `freezeBlur` performance lock during turns, configurable Curl Strength/Shadow/Speed/Page-Back/Grab-Zone inside `AaGlassSheet`, and automatic `Reduce Motion` crossfade/snap compliance.
- **PDF Text Reflow & Reading Insights (Milestone G)**:
  - **Pure-Kotlin PDF Text Reflow (`PdfReflowExtractor`)**: Extracts readable paragraphs and headings on demand from uncompressed or `/FlateDecode` PDF content streams (including `/ToUnicode` CMaps and `Tj`/`TJ`/`Td`/`Tm`/`Tf` operators) with non-destructive source preservation, graceful scanned/image-page fallback banner, and full reflowable reader features (custom fonts, margins, highlights, dictionary tap-to-define, and Page Curl).
  - **Local Reading Insights & Streaks (`ReadingStatsRepository`, `ReadingStatsSheet`)**: Room v5 `reading_sessions` table tracking active reading minutes, daily streaks, 7-day Compose Canvas bar chart, pages turned, and per-book breakdowns cleanly accessible from Library and Settings.
- **Startup Warmup & Baseline Profiles (Milestone H)**:
  - **Baseline Profile & Memory Polish (`baseline-prof.txt`, `MochiApplication`)**: Off-main-thread lazy container/library/theme warmup, `onTrimMemory` LRU bitmap trimming on `PdfPageEngine`, and ART Baseline Profile rules for startup, library scrolling, reader pagination, PDF rendering, and Page Curl paths.

## Known Gaps & Architectural Decisions
- **Native `PdfRenderer` & `PdfDocument` instead of PDFium**: PDFium native `.so` binaries are not bundled in the offline environment; `PdfPageEngine` and `StudioExporter` use Android's built-in `PdfRenderer` and `PdfDocument` (0 extra APK bloat, 100% offline), complemented by pure-Kotlin `PdfReflowExtractor` for text reflow. Interactive PDF AcroForm field editing is out of scope for now.
- **Pure-Kotlin EPUB/GFM Engine instead of Readium / `commonmark-java`**: Readium Kotlin Toolkit and `commonmark-java` are not available in the offline build environment; Mochi uses custom zero-network pure-Kotlin EPUB 2/3, GFM Markdown, TXT, and CBZ parsers (`DocumentParsers`) paired with Compose `TextMeasurer` pagination (`ReaderPaginator`), eliminating WebView overhead while keeping full locator fidelity.
- **Material 3 Expressive alpha APIs**: Compose BOM `2024.09.00` (Material 3 `1.3.0`) does not yet ship `MaterialExpressiveTheme` / `MotionScheme.expressive()` as stable APIs; implemented via our thin `MochiMotionTokens` + custom expressive components so upgrading to M3 1.4+ is a one-layer swap.
- **Alternate launcher icon switching**: Alternate pastel icons are previewed and selectable for in-app branding/badges without disabling `MainActivity` component aliases.
